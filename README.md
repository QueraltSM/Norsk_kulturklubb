# Norwegian Learning Platform

![Image](https://github.com/user-attachments/assets/2ae19968-37bd-442f-a782-02474a65ce01)

## Project Overview  
This Master’s Thesis project introduces a web platform designed to facilitate the learning of the Norwegian language by integrating linguistic and cultural content. The platform provides structured lessons organized by proficiency levels, an integrated translator, access to qualified teachers, cultural blogs, and virtual events to practice the language and connect with other learners.

The platform welcomes Norwegian learners by offering a wide range of resources tailored to support their learning journey. Teachers contribute high-quality educational content, create interactive sessions, and organize workshops to enhance the online learning experience. Contributors enrich the platform culturally by writing blog posts and hosting virtual events that foster social interaction and provide immersive language practice.

By bringing together students, teachers, and enthusiasts, the platform fosters a dynamic and collaborative community that promotes knowledge exchange, authentic language use, and meaningful connections. Built with modern web technologies, this project aims to significantly contribute to Norwegian language education worldwide while promoting appreciation of Norway’s rich cultural heritage.

## Key Features  
- **Structured Lessons**: Organized content by levels for progressive learning.  
- **Online Teachers**: Professionals delivering lessons and interactive events.  
- **Cultural Content**: Blogs and materials exploring Norwegian culture.  
- **Virtual Events**: Classes, workshops, and social meetings to practice and engage.  
- **Collaborative Community**: A space for learners and educators to interact and share knowledge.

## Technologies Used

- **HTML5 & CSS3**: For building the structure and visual design of the platform.  
- **JavaScript (with jQuery)**: Enables interactivity and dynamic content manipulation.  
- **Bootstrap**: Front-end framework for responsive design and consistent UI components.  
- **Node.js & Express.js**: Backend server environment and framework managing HTTP requests.  
- **Amazon Web Services (AWS)**:  
  - **DynamoDB**: NoSQL database storing user data, lessons, and event records.  
  - **S3**: Secure and scalable storage for multimedia files like profile images and lesson materials.  
  - **Amazon Comprehend & Amazon Translate**: Language detection and automatic translation services.  
- **Supporting Tools & Libraries**:  
  - **Visual Studio Code**: Lightweight code editor used for development and debugging.  
  - **Git**: Version control system for code management and tracking changes.  
  - **Middleware & Modules**: Cors (cross-origin resource sharing), Multer (file uploads), Body-parser (request parsing), fs and Path (file system utilities).  
  - **Flatpickr**: JavaScript library for intuitive date selection inputs.
